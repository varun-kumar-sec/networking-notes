# Common Network Attacks
# 📖 Overview

**Network attacks** are attempts to gain unauthorized access, steal information, disrupt services, or compromise network systems.

# 🔑 Attack Summary

| Attack                 | Purpose                           | Basic Mitigation                          |
| ---------------------- | --------------------------------- | ----------------------------------------- |
| **Malware**            | Damage or compromise systems      | Antivirus, patching, backups              |
| **Phishing**           | Steal credentials/information     | MFA, filtering, awareness                 |
| **DoS**                | Disrupt availability              | Filtering, rate limiting, DDoS protection |
| **MitM**               | Intercept communication           | Encryption, HTTPS/TLS, VPN                |
| **Password Attacks**   | Obtain credentials                | Strong passwords, MFA                     |
| **Spoofing**           | Impersonate trusted systems/users | Authentication, filtering                 |
| **Network Sniffing**   | Capture network traffic           | Encryption, secure protocols              |
| **Social Engineering** | Manipulate users                  | Awareness, verification, MFA              |

#📌 Key Takeaways

Network attacks target users, devices, networks, applications, and data.
Common attacks include malware, phishing, DoS, MitM, password attacks, spoofing, sniffing, and social engineering.
Use MFA, firewalls, encryption, patching, endpoint protection, IDS/IPS, monitoring, and backups for layered protection.
