# Phishing
# 📖 Overview

**Phishing** is a social engineering attack in which an attacker impersonates a trusted person, organization, or service to trick users into revealing sensitive information, opening malicious content, transferring money, or performing another unsafe action.

Phishing commonly uses **email**, but it can also occur through text messages, phone calls, social media, and other communication platforms.

# 🎣 What is Phishing?

Phishing relies on **social engineering** to manipulate users into taking an action that benefits the attacker.

Common attacker goals include:

- Stealing usernames and passwords
- Obtaining financial information
- Installing malware
- Stealing sensitive data
- Taking over accounts
- Redirecting users to malicious websites

```text
Attacker
   │
   ▼
Fake Message / Website
   │
   ▼
User Trusts the Message
   │
   ▼
User Takes Action
```

# 🧩 Types of Phishing

| Type                                | Description                                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Email Phishing**                  | Uses fraudulent emails to trick users.                                                                   |
| **Spear Phishing**                  | Targets a specific person or organization using customized information.                                  |
| **Whaling**                         | Targets high-level executives or other important individuals.                                            |
| **Smishing**                        | Phishing performed through SMS or text messages.                                                         |
| **Vishing**                         | Phishing performed through voice calls.                                                                  |
| **Clone Phishing**                  | Creates a fraudulent copy of a legitimate message or link.                                               |
| **Business Email Compromise (BEC)** | Impersonates a trusted business account or person to request sensitive information or financial actions. |

# ⚠️ Common Phishing Indicators

Be cautious when a message contains:

Urgent or threatening language
Unexpected requests for credentials
Suspicious links
Unknown or slightly altered sender addresses
Unexpected attachments
Requests for money or gift cards
Requests for sensitive information
Spelling or grammatical errors
Messages that create unusual pressure to act quickly

Modern phishing messages can be well-written and may contain accurate branding, so grammar alone should not be used to determine whether a message is legitimate.

# 💼 Phishing Example

An attacker sends a fake message claiming to be from a bank.

Fake Bank Message
       │
       ▼
"Your account will be locked!"
       │
       ▼
User Clicks Link
       │
       ▼
Fake Login Page
       │
       ▼
Credentials Stolen

The attacker may then use the stolen credentials to access the victim's account.

# 🛡️ Phishing Prevention

Users and organizations can reduce phishing risks by:

Verifying unexpected requests independently.
Checking sender addresses carefully.
Avoiding suspicious links and attachments.
Using MFA.
Using email filtering and security tools.
Keeping software and browsers updated.
Using password managers where appropriate.
Providing security awareness training.
Reporting suspicious messages.
Using secure authentication methods such as phishing-resistant MFA where available.

---

# 🚨 Phishing Response

If you suspect that you interacted with a phishing message:

Stop interacting with the message.
Report it to the appropriate IT/security team.
Change compromised passwords.
Revoke active sessions when appropriate.
Enable or strengthen MFA.
Check for suspicious account activity.
Run appropriate security checks if malware may have been downloaded.
Contact the affected service provider when necessary.

# 📌 Key Takeaways

Phishing is a social engineering attack that tricks users into performing unsafe actions.
Phishing can target credentials, financial information, sensitive data, or system access.
Common forms include email phishing, spear phishing, whaling, smishing, vishing, clone phishing, and BEC.
Suspicious links, attachments, urgent requests, unusual sender addresses, and requests for sensitive information are common warning signs.
MFA, user awareness, email filtering, careful verification, secure authentication, and prompt reporting help reduce phishing risks.
If credentials are compromised, passwords should be changed and affected sessions/accounts should be secured promptly.
