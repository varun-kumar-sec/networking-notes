# 📖 Overview

**Social engineering** is a cybersecurity technique in which attackers manipulate people into revealing sensitive information, granting access, transferring money, or performing actions that weaken security.

Instead of primarily exploiting a technical vulnerability, social engineering exploits **human behavior, trust, emotions, and decision-making**.

# 🧠 What is Social Engineering?

Social engineering is the manipulation of people to obtain information or perform an action that benefits an attacker.

```text
Attacker
   │
   ▼
Manipulates Human Behavior
   │
   ▼
Victim Trusts the Request
   │
   ▼
Victim Takes Action
   │
   ▼
Information / Access / Money Compromised
```
Attackers may exploit:

Trust
Fear
Urgency
Curiosity
Authority
Greed
Helpfulness

# 🧩 Common Social Engineering Techniques

| Technique          | Description                                                                                        |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| **Phishing**       | Uses fraudulent messages to trick users into revealing information or performing an unsafe action. |
| **Spear Phishing** | Targets a specific person or organization with a customized message.                               |
| **Whaling**        | Targets senior executives or other high-value individuals.                                         |
| **Smishing**       | Social engineering through SMS or text messages.                                                   |
| **Vishing**        | Social engineering through voice calls.                                                            |
| **Pretexting**     | Creates a believable false story or identity to obtain information.                                |
| **Baiting**        | Uses an attractive offer or item to encourage a victim to take an unsafe action.                   |
| **Quid Pro Quo**   | Offers a supposed benefit or service in exchange for information or action.                        |
| **Tailgating**     | Follows an authorized person into a restricted physical area.                                      |
| **Impersonation**  | Pretends to be a trusted employee, technician, organization, or authority.                         |

# 🎭 Psychological Manipulation

Attackers commonly create a sense of:

Urgency – "Act immediately."
Fear – "Your account will be disabled."
Authority – "I am calling from IT."
Trust – Pretending to be a known person.
Curiosity – Offering an interesting file or link.
Reward – Promising money, prizes, or benefits.

# 💼 Social Engineering Examples

Example 1: Fake IT Support

An attacker calls an employee pretending to be an IT technician and asks for their password.

Attacker
   │
   ▼
Pretends to be IT Support
   │
   ▼
Creates Trust
   │
   ▼
Requests Credentials
   │
   ▼
Account May Be Compromised
Example 2: Phishing Email

An attacker sends a fake password-reset message containing a malicious or fraudulent link.

Example 3: Tailgating

An unauthorized person follows an employee through a secure door without using their own access credentials.

# ⚠️ Warning Signs

Be cautious when someone:

Creates unusual urgency.
Requests passwords or MFA codes.
Requests confidential information.
Claims to have authority but cannot be verified.
Asks for unexpected payments or transfers.
Sends suspicious links or attachments.
Requests that normal security procedures be bypassed.
Uses an unusual communication method.
Discourages independent verification.

Legitimate IT or security personnel should not normally ask users to disclose their passwords.

---

# 🛡️ Prevention and Mitigation

Organizations can reduce social engineering risks by:

Providing regular security awareness training.
Using MFA.
Enforcing strong access controls.
Applying least privilege.
Verifying unusual requests independently.
Establishing clear security procedures.
Using email and web filtering.
Implementing physical access controls.
Monitoring suspicious account activity.
Encouraging employees to report suspicious behavior.
Using phishing-resistant authentication where appropriate.
Verification Principle
Unexpected Request
       │
       ▼
Do Not Trust Immediately
       │
       ▼
Verify Through a Trusted Channel
       │
       ▼
Proceed Only if Legitimate

# 🚨 Response to a Social Engineering Attack

If you suspect that you have been targeted:

Stop the interaction.
Do not provide additional information.
Do not click suspicious links or open unexpected attachments.
Verify the request using a trusted communication method.
Report the incident to IT/security.
Change compromised passwords.
Revoke active sessions when appropriate.
Monitor affected accounts and systems.
Follow the organization's incident-response procedures.

# 📌 Key Takeaways

Social engineering attacks exploit human behavior rather than relying only on technical vulnerabilities.
Attackers commonly exploit trust, fear, urgency, authority, curiosity, and greed.
Common techniques include phishing, spear phishing, whaling, smishing, vishing, pretexting, baiting, quid pro quo, tailgating, and impersonation.
Always verify unusual requests through a trusted, independent communication channel.
Never share passwords or MFA codes with someone simply because they claim to be an IT employee or trusted authority.
Security awareness, MFA, least privilege, access controls, filtering, verification, and reporting help reduce social engineering risks.
Social engineering can lead to credential theft, malware infection, financial fraud, unauthorized access, and data breaches.
