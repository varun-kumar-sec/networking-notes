# CIA Triad
# 📖 Overview

The **CIA Triad** is a fundamental model in information and network security. It consists of three core security objectives:

- **Confidentiality** – Protect information from unauthorized access.
- **Integrity** – Protect information from unauthorized modification.
- **Availability** – Ensure information and systems are accessible when needed.

# 📌 Key Takeaways

Confidentiality → Prevent unauthorized disclosure.
Integrity → Prevent unauthorized modification.
Availability → Keep systems and data accessible.
The three principles work together to provide a foundation for network and information security.
