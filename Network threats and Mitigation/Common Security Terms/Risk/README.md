# Risk
# 📖 Overview

**Risk** is the potential for loss, damage, or negative impact when a **threat exploits a vulnerability**.

In cybersecurity, risk helps organizations understand which security problems are most important and where security controls should be applied.

A simple way to understand risk is:

```text
Threat + Vulnerability
          │
          ▼
         Risk
          │
          ▼
     Potential Impact
```
Risk is commonly considered in terms of both likelihood and impact.

# ⚠️ What is Risk?

Risk is the possibility that a security event will cause harm to an organization, system, network, or data.

Risk exists when a threat can take advantage of a vulnerability and produce an unwanted impact.

      ▼
   Threat
      │
      ▼
   Exploitation
      │
      ▼
    Attack
      │
      ▼
     Risk
      │
      ▼
Potential Impact

---

# 📊 Risk Components

| Component     | Meaning                         |
| ------------- | ------------------------------- |
| Threat        | Potential source of harm.       |
| Vulnerability | Weakness that can be exploited. |
| Impact        | Possible damage or loss.        |

Risk is also commonly evaluated using:

Likelihood – How likely the event is to occur.
Impact – How serious the consequences would be.

A simplified risk relationship is:

Risk ≈ Likelihood × Impact

---

# 📈 Likelihood and Impact
Likelihood

Likelihood represents the probability that a security event will occur.

Examples:

Low likelihood
Medium likelihood
High likelihood
Impact

Impact represents the severity of the consequences.

Examples:

Minor data loss
Service disruption
Financial loss
Privacy violation
Major operational disruption

A high-likelihood event with high impact generally requires greater attention.

# 🧩 Types of Security Risk

Risk can be understood using three main factors:
| Risk Type          | Example                                           |
| ------------------ | ------------------------------------------------- |
| Cybersecurity Risk | Malware compromises a server.                     |
| Data Risk          | Sensitive information is exposed.                 |
| Operational Risk   | Network outage disrupts business operations.      |
| Financial Risk     | Security incident causes financial loss.          |
| Compliance Risk    | Organization fails to meet security requirements. |
| Reputational Risk  | Security breach reduces customer trust.           |
| Physical Risk      | Fire damages network infrastructure.              |

# 🛡️ Risk Mitigation

Organizations can reduce risk by applying appropriate security controls.

Common methods include:

Security patching
Firewalls
Strong authentication
Multi-factor authentication
Access control
Encryption
Network segmentation
Endpoint protection
Security monitoring
Backups
Security awareness training
Vulnerability assessments

Risk can also be managed by:

Avoiding the risky activity.
Reducing the likelihood or impact.
Transferring some risk to another party.
Accepting the risk when it is understood and within an acceptable level.

# 🔗 Vulnerability, Threat, Attack, and Risk

| Term          | Meaning                                                                              |
| ------------- | ------------------------------------------------------------------------------------ |
| Vulnerability | A weakness in a system or security control.                                          |
| Threat        | A potential source of harm.                                                          |
| Exploit       | A method used to take advantage of a vulnerability.                                  |
| Attack        | An actual attempt to compromise a target.                                            |
| Risk          | The potential for loss or damage resulting from a threat exploiting a vulnerability. |

Simple Example

A server has an unpatched vulnerability. An attacker represents a threat. The attacker uses an exploit to perform an attack. The possibility of system compromise and resulting damage represents the risk.

# 📌 Key Takeaways

Risk is the potential for loss or damage resulting from security threats and vulnerabilities.
Risk is commonly evaluated using likelihood and impact.
A vulnerability creates an opportunity for a threat to cause harm.
An exploit can be used to take advantage of a vulnerability.
An attack is an actual attempt to compromise a target.
Risk assessment helps organizations identify and prioritize security problems.
Risk can be managed through avoidance, reduction, transfer, or acceptance.
Security controls such as patching, MFA, firewalls, encryption, access control, monitoring, and backups help reduce security risk.
