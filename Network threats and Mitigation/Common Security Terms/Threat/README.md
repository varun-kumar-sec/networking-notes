# Threat
# 📖 Overview

A **threat** is a potential event, action, or circumstance that could exploit a vulnerability and cause harm to a system, network, device, user, or data.

A threat represents **potential danger**, while an attack is an actual attempt to cause harm.

# ⚠️ What is a Threat?

A threat is anything that has the **potential to exploit a vulnerability** and negatively affect a system or network.

Threats may be caused by people, software, environmental events, or accidental actions.

```text

      │

      │
      ▼

      ▼
Potential Damage
```

# 👥 Sources of Threats

| Source        | Description                             | Example                      |
| ------------- | --------------------------------------- | ---------------------------- |
| External      | Originates outside the organization     | Internet-based attacker      |
| Internal      | Originates within the organization      | Malicious employee           |
| Human         | Caused by human actions                 | Phishing or misconfiguration |
| Malware       | Caused by malicious software            | Ransomware                   |
| Environmental | Caused by physical or natural events    | Fire or flood                |
| Technical     | Caused by system or technology problems | Hardware failure             |

# 🧩 Types of Threats

Intentional Threats

Deliberately created to compromise systems or information.

Examples:

Hacking
Malware
Password attacks
Data theft
DDoS attacks
Accidental Threats

Occur without malicious intent.

Examples:

Incorrect configuration
Accidental data deletion
Sending information to the wrong person
Connecting an infected device
Environmental Threats

Threats caused by physical or natural conditions.

Examples:

Fire
Flood
Earthquake
Power failure
Excessive temperature

# 🔗 Threat, Vulnerability, and Exploit

These terms are related but have different meanings:
| Term          | Meaning                                             |
| ------------- | --------------------------------------------------- |
| Vulnerability | A weakness that can be exploited.                   |
| Threat        | A potential source of harm or danger.               |
| Exploit       | A method used to take advantage of a vulnerability. |
| Attack        | An actual attempt to compromise a system.           |
| Impact        | The result or damage caused by a successful attack. |

Simple Example
A server has an unpatched vulnerability. An attacker represents a threat. The attacker uses an exploit to take advantage of the vulnerability. The resulting unauthorized access is part of the attack and its impact.

# ⚔️ Threat vs Attack

| Threat                                  | Attack                                           |
| --------------------------------------- | ------------------------------------------------ |
| Potential danger                        | Actual attempt                                   |
| May never occur                         | Actively carried out                             |
| Represents possible harm                | Attempts to cause or achieve harm                |
| Example: attacker could target a server | Example: attacker attempts to exploit the server |

# 🔐 Threats and the CIA Triad

Threats can affect all three components of the CIA Triad:

CIA Component	Example Threat
Confidentiality	Data theft or eavesdropping
Integrity	Unauthorized data modification
Availability	DoS/DDoS or hardware failure

# 📌 Key Takeaways

A threat is a potential source of harm to a system, network, user, or data.
Threats can be external, internal, human, technical, malware-based, or environmental.
Threats can be intentional or accidental.
A vulnerability is a weakness, while a threat represents potential danger.
An exploit is a method used to take advantage of a vulnerability.
An attack is an actual attempt to compromise a target.
Threats can affect Confidentiality, Integrity, and Availability.
Security controls, monitoring, patching, access control, backups, and user awareness help reduce threats and their impact.
