# 🔑 Key Terms

| Term              | Meaning                                             | Example            |
| ----------------- | --------------------------------------------------- | ------------------ |
| **Vulnerability** | A weakness that can be exploited.                   | Unpatched software |
| **Exploit**       | A method used to take advantage of a vulnerability. | Exploit code       |
| **Threat**        | A potential source of harm.                         | Cybercriminal      |
| **Attack**        | An actual or attempted action against a target.     | Phishing attack    |
| **Risk**          | Potential for loss or damage.                       | Data breach        |

# 📌 Key Takeaways

Vulnerability = Weakness
Exploit = Method to use the weakness
Threat = Potential danger
Attack = Attempted/actual harmful action
Risk = Potential loss or damage
Security controls reduce the likelihood or impact of risk.
