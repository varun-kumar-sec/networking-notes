# Network Security
# 📖 Overview

**Network security** is the practice of protecting computer networks, devices, systems, applications, and data from unauthorized access, misuse, attacks, and other security threats.

Network security uses a combination of **technologies, policies, procedures, and security controls** to protect network resources and maintain the confidentiality, integrity, and availability of information.

A secure network is not based on a single security tool. Instead, multiple layers of protection are used to reduce the likelihood and impact of security incidents.

# 🌐 What is Network Security?

Network security involves protecting a network against threats that could compromise its:

- Devices
- Services
- Applications
- Data
- Users
- Network infrastructure

The goal is to allow authorized users to access network resources while preventing unauthorized access and malicious activity.

---

# 🎯 Goals of Network Security

Network security focuses on three primary objectives, commonly known as the **CIA Triad**:

| Objective | Purpose |
|---|---|
| Confidentiality | Prevent unauthorized access to information. |
| Integrity | Prevent unauthorized modification of information. |
| Availability | Ensure authorized users can access resources when needed. |

These three objectives form the foundation of information and network security.

# 🛡️ Common Network Security Controls

Network security uses different controls to protect systems and data.

### Firewall

A firewall monitors and controls network traffic based on defined security rules.

### Authentication

Authentication verifies the identity of a user or device.

Examples:

- Passwords
- Multi-factor authentication
- Digital certificates
- Biometrics

### Access Control

Access control determines which users or devices are allowed to access specific resources.

### Encryption

Encryption converts readable information into an encoded form to prevent unauthorized users from understanding it.

### Antivirus and Endpoint Protection

Security software helps detect, prevent, and remove malicious software from computers and other endpoints.

### IDS and IPS

- **IDS (Intrusion Detection System)** detects suspicious or malicious activity.
- **IPS (Intrusion Prevention System)** can detect and actively block suspicious activity.

### Network Segmentation

Network segmentation divides a network into separate sections to limit access and reduce the spread of attacks.

### Security Updates and Patching

Regular updates fix known vulnerabilities and reduce the opportunity for attackers to exploit outdated software.

### Backups

Backups provide a way to recover important data after incidents such as ransomware, accidental deletion, or hardware failure.

# 🧱 Defense in Depth

**Defense in depth** is a security strategy that uses multiple layers of protection instead of relying on a single security control.

For example:

```text
Internet
   │
   ▼
Firewall
   │
   ▼
Network Segmentation
   │
   ▼
Authentication
   │
   ▼
Endpoint Protection
   │
   ▼
Encryption
   │
   ▼
Protected Data

```

# 🔄 Network Security Layers

Security controls can be applied at multiple levels:

Layer	Example
Physical- Locked server rooms
Network-	Firewalls, IDS/IPS
Device-	Endpoint protection
Application-	Secure configuration
Data-	Encryption and backups

Using multiple layers provides stronger overall protection.

# 📌 Key Takeaways
Network security protects networks, devices, systems, applications, users, and data from security threats.
The three primary security objectives are Confidentiality, Integrity, and Availability (CIA).
Common security controls include firewalls, authentication, access control, encryption, endpoint protection, IDS/IPS, segmentation, patching, monitoring, and backups.
Least privilege limits users and systems to only the access they require.
Defense in depth uses multiple layers of security instead of relying on a single control.
Network security requires both technical controls and organizational policies.
User awareness is an important part of network security because human actions can introduce security risks.
Regular patching, monitoring, backups, access control, and security awareness help reduce security risks.
No single security control can protect against every threat; effective security requires multiple complementary controls.
