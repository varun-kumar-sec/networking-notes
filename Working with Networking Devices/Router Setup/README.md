# Router Setup
# 📖 Overview

Setting up a router is one of the first tasks when creating a home or small office network. A properly configured router provides Internet connectivity, allows wired and wireless devices to communicate, and helps secure the network from unauthorized access.

Router setup involves more than simply connecting cables. It includes choosing the right location, connecting the router to the Internet, configuring wireless settings, securing the administrator account, and verifying that everything is working correctly.

This section walks through the essential steps required to successfully deploy a router.

# 🛠️ Why Proper Router Setup is Important

Correct router setup provides several benefits:

- Reliable Internet connectivity.
- Better wireless coverage.
- Improved network performance.
- Enhanced network security.
- Reduced troubleshooting later.
- Stable communication between connected devices.

Skipping configuration or security steps can lead to weak Wi-Fi, connectivity issues, or unauthorized access.

---

# 🛡️ Security During Router Setup

Security should always be part of the initial setup process.

Recommended practices include:

- Change the default administrator password.
- Configure WPA3 or WPA2 wireless security.
- Use a strong Wi-Fi password.
- Keep the router firmware updated.
- Allow only authorized users to access the router's management interface.

These measures help protect both the router and the connected devices.
