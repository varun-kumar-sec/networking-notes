# Configure Wi-Fi Settings
# 📖 Overview

After connecting the router to the Internet, the next step is to configure the **Wi-Fi settings**. Proper wireless configuration allows laptops, smartphones, tablets, smart TVs, and other wireless devices to securely connect to the network.

A well-configured Wi-Fi network improves security, performance, and user experience while protecting the network from unauthorized access.

---

- Configure a wireless network on a router.

# 🌐 Why Configure Wi-Fi?

Wi-Fi configuration allows wireless devices to connect to the network without using Ethernet cables.

Proper configuration helps:

- Secure the wireless network.
- Improve wireless performance.
- Prevent unauthorized users from connecting.
- Provide reliable Internet access.
- Optimize wireless coverage.

---

# 🛠️ Steps to Configure Wi-Fi

## Step 1: Access the Router

Open a web browser and enter the router's management IP address.

Common examples include:

```text
192.168.0.1
192.168.1.1
```

Log in using the administrator credentials.

---

## Step 2: Configure the SSID

The **SSID (Service Set Identifier)** is the name of the wireless network that users see when searching for available Wi-Fi networks.

Example:

```text
Home_Network
Office_WiFi
```

Choose an SSID that is easy to recognize but does not reveal sensitive information such as your address or organization.

---

## Step 3: Select the Security Mode

Choose a modern wireless security protocol.

Recommended:

- WPA3 (Preferred)
- WPA2 (If WPA3 is unavailable)

Avoid:

- WEP
- Open (No Password)

These options provide little or no protection against unauthorized access.

---

## Step 4: Create a Strong Wi-Fi Password

Choose a password that:

- Contains at least 12 characters.
- Includes uppercase and lowercase letters.
- Includes numbers.
- Includes special characters.
- Is difficult to guess.

Example:

```text
N3tw0rk@2026!
```

Avoid using simple passwords such as:

```text
12345678
password
wifi1234
```

---

## Step 5: Select the Wireless Frequency Band

Many modern routers support:

### 2.4 GHz

- Longer range.
- Better wall penetration.
- Lower maximum speed.
- More susceptible to interference.

### 5 GHz

- Faster speeds.
- Less interference.
- Shorter range.
- Better for high-speed activities.

Dual-band routers can provide both bands simultaneously.

---

## Step 6: Save the Settings

Click:

```text
Save
```

or

```text
Apply
```

The router may restart its wireless service.

---

# ✅ Verify the Configuration

After saving the settings:

- Search for the new Wi-Fi network.
- Connect using the configured password.
- Verify Internet access.
- Test connectivity from multiple devices if possible.

---

# 🛡️ Best Practices

When configuring Wi-Fi:

- Use WPA3 whenever available.
- Create a strong wireless password.
- Change the default SSID if appropriate.
- Keep router firmware updated.
- Change the administrator password.
- Place the router in a central location.
- Review connected devices periodically.

# 📌 Key Takeaways

- Wi-Fi configuration allows wireless devices to connect securely to the network.
- The SSID identifies the wireless network.
- WPA3 (or WPA2 if necessary) should be used for wireless security.
- Strong passwords help prevent unauthorized access.
- Always verify connectivity after saving the router configuration.
