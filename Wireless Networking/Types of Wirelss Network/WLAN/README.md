# Wireless Local Area Network (WLAN)
# 📖 Overview

A **Wireless Local Area Network (WLAN)** is a wireless network that connects devices within a limited geographic area such as a home, office, school, or campus.

Unlike a traditional wired LAN, a WLAN allows devices to communicate without using Ethernet cables. Instead, devices communicate using **radio waves**, typically through a **Wireless Access Point (WAP)**.

Today, WLANs are the most common type of wireless network and are widely used to provide Internet access and local network connectivity.

# 🌐 What is WLAN?

A **Wireless Local Area Network (WLAN)** is a wireless network designed to connect multiple devices within a relatively small area.

Devices communicate through a **Wireless Access Point (WAP)**, which allows them to exchange data and access network resources without physical cables.

Examples include:

- Home Wi-Fi networks
- Office wireless networks
- School and university Wi-Fi
- Coffee shop Wi-Fi
- Airport Wi-Fi

---

# ⚙️ How WLAN Works

A WLAN generally works as follows:

1. A Wireless Access Point broadcasts a wireless signal.
2. Wireless devices detect the available network.
3. Devices connect to the access point.
4. Data is transmitted between devices and the network using radio waves.

The access point also provides access to other networks such as the Internet.

---

# 📏 Coverage Area

Typical WLAN coverage:

```text
Approximately 30 to 100 meters
```

Coverage depends on:

- Obstacles (walls, furniture, etc.)
- Signal strength
- Wireless equipment
- Frequency band

# 📡 Common WLAN Technologies

The most common technology used in WLAN is:

- Wi-Fi (IEEE 802.11)

> Wi-Fi standards and versions are discussed in detail in the **Wi-Fi** section of this module.

---

# ✅ Advantages

- No network cables required.
- Supports user mobility.
- Easy installation.
- Simple network expansion.
- Multiple devices can connect simultaneously.
- Convenient Internet access.

---

# ❌ Limitations

- Limited coverage area.
- Signal interference from other wireless devices.
- Lower security if not properly configured.
- Performance can decrease as more devices connect.

---
