# Wireless Network Modes

> Learn how wireless devices communicate with one another and understand the different modes of wireless network operation.

---

# 📖 Overview

Wireless devices can communicate using different **network modes**, depending on how the network is designed.

A wireless network mode defines **how devices connect and exchange data**. Some modes allow devices to communicate directly with each other, while others rely on a central networking device such as a **Wireless Access Point (WAP)**.

Understanding wireless network modes helps explain how wireless communication is established in different networking environments.
