# Wireless Security

> Learn the fundamentals of wireless network security, understand common Wi-Fi security protocols, and explore how wireless networks are protected from unauthorized access.

---

# 📖 Overview

Wireless networks transmit data through **radio waves**, making communication more accessible but also more vulnerable to unauthorized access than traditional wired networks.

Without proper security, attackers may intercept wireless traffic, gain unauthorized access to the network, or compromise sensitive information.

To protect wireless communication, various security protocols have been developed over time. This section introduces the evolution of Wi-Fi security, from the early **Wired Equivalent Privacy (WEP)** protocol to the improved **Wi-Fi Protected Access (WPA)** protocol.

Understanding these protocols helps build a strong foundation for securing wireless networks.

# 🔒 Why Wireless Security Matters

Wireless security helps to:

- Prevent unauthorized network access.
- Protect confidential information.
- Secure communication between wireless devices.
- Reduce the risk of data interception.
- Maintain the integrity of wireless networks.

Without appropriate security measures, nearby attackers may be able to access or monitor wireless communications.

---

# 📌 Key Takeaways

- Wireless networks require security because they communicate over radio waves.
- Security protocols encrypt wireless communication and authenticate users.
- **WEP** was the first widely used Wi-Fi security protocol but is now considered insecure.
- **WPA** improved wireless security with stronger encryption and authentication.
- Modern wireless networks typically use newer protocols such as **WPA2** or **WPA3**, but understanding WEP and WPA is important for learning the evolution of wireless security.
