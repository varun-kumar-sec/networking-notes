# Wi-Fi Protected Access (WPA)
# 📖 Overview

**Wi-Fi Protected Access (WPA)** is a wireless security protocol developed to improve the security of Wi-Fi networks.

It was introduced as a replacement for **Wired Equivalent Privacy (WEP)** after researchers discovered several serious security weaknesses in WEP.

WPA provides stronger authentication and encryption, making wireless communication significantly more secure than WEP.

Although WPA greatly improved wireless security, it has also been succeeded by newer standards such as **WPA2** and **WPA3**.

# 🌐 What is WPA?

**Wi-Fi Protected Access (WPA)** is a wireless security protocol designed to protect Wi-Fi networks from unauthorized access and data interception.

It improves wireless security by providing:

- Stronger encryption
- Better authentication
- Improved protection against common attacks

WPA was designed as an intermediate solution before the release of WPA2.

---

# ❓ Why WPA Was Developed

WPA was introduced because WEP had several security flaws that made wireless networks vulnerable to attacks.

The goals of WPA were to:

- Improve wireless encryption.
- Strengthen user authentication.
- Protect wireless communication from unauthorized access.
- Increase the overall security of Wi-Fi networks.

---

# ⚙️ How WPA Works

A WPA-protected network generally works as follows:

1. A wireless device attempts to connect to the Wi-Fi network.
2. The device provides the correct network credentials.
3. The access point authenticates the device.
4. A secure encrypted communication channel is established.
5. Data is transmitted securely between the device and the access point.

Unlike WEP, WPA uses improved key management, making it much more difficult for attackers to compromise the network.

---

# ✅ Advantages

- More secure than WEP.
- Improved encryption.
- Better authentication mechanisms.
- More resistant to wireless attacks.
- Supported by most modern wireless devices.

---

# ❌ Limitations

- Older than WPA2 and WPA3.
- Less secure than newer wireless security standards.
- Some older implementations have known vulnerabilities.
- Modern networks generally use WPA2 or WPA3 instead.

---

| Feature | WEP | WPA |
|----------|-----|-----|

# 📌 Key Takeaways

- WPA stands for **Wi-Fi Protected Access**.
- It was developed to replace the insecure WEP protocol.
- WPA provides stronger encryption and improved authentication.
- It offers much better protection than WEP.
- Although WPA is more secure than WEP, **WPA2** and **WPA3** are the preferred choices for modern wireless networks.
