# Wireless Access Point (WAP)
# 📖 Overview

A **Wireless Access Point (WAP)** is a networking device that allows wireless devices to connect to a wired network using **Wi-Fi**.

It acts as a bridge between wireless clients and the wired Local Area Network (LAN), enabling laptops, smartphones, tablets, and other Wi-Fi-enabled devices to communicate with each other and access the Internet.

Wireless Access Points are commonly used in homes, offices, schools, hotels, airports, and public places to provide wireless network coverage.

# 🌐 What is a Wireless Access Point?

A **Wireless Access Point (WAP)** is a networking device that provides wireless connectivity to nearby devices.

It receives data from the wired network and transmits it wirelessly using radio waves. Similarly, it receives wireless data from client devices and forwards it to the wired network.

A WAP allows multiple wireless devices to communicate over the same network.

---

# ❓ Why is a WAP Required?

A Wireless Access Point is used to:

- Provide Wi-Fi connectivity.
- Extend wireless network coverage.
- Connect wireless devices to a wired LAN.
- Allow multiple users to share network resources.
- Enable Internet access for wireless devices.

---

# ⚙️ How a WAP Works

A Wireless Access Point generally operates as follows:

1. The WAP is connected to the wired network.
2. It broadcasts a wireless network (SSID).
3. Wireless devices detect the available network.
4. Devices authenticate and connect.
5. The WAP forwards data between the wireless devices and the wired network or the Internet.

---

# ⭐ Characteristics

A Wireless Access Point provides:

- Wireless network coverage
- Communication between wired and wireless networks
- Support for multiple wireless clients
- Wi-Fi connectivity
- Centralized wireless communication

---

# ✅ Advantages

- Eliminates the need for network cables.
- Supports multiple wireless devices.
- Expands wireless coverage.
- Easy to deploy and manage.
- Improves user mobility.

---

# ❌ Limitations

- Limited coverage area.
- Signal interference may affect performance.
- Requires proper placement for optimal coverage.
- Performance decreases as more devices connect.
