# Wireless Network Devices

> Learn about the hardware devices that enable wireless communication and understand how they work together to build a wireless network.

---

# 📖 Overview

Wireless networking relies on specialized hardware devices that enable computers, smartphones, tablets, and other electronic devices to communicate without physical cables.

Every wireless network consists of two primary components:

- A **Wireless Network Interface Card (WNIC)** installed in the client device.
- A **Wireless Access Point (WAP)** that provides wireless connectivity to the network.

Together, these devices establish and maintain wireless communication between users and the network.

# 🔄 How They Work Together

A wireless connection is established through the following process:

1. The **WNIC** detects available Wi-Fi networks.
2. The user selects a wireless network.
3. The **WAP** authenticates the connection.
4. The WNIC and WAP exchange data using radio waves.
5. The WAP forwards traffic to the wired network or the Internet.
