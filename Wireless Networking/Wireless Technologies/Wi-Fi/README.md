# Wi-Fi
# 📖 Overview

**Wi-Fi** is a wireless networking technology that allows devices to connect to a **Wireless Local Area Network (WLAN)** without using physical cables.

It uses **radio waves** to transmit and receive data between wireless devices and a **Wireless Access Point (WAP)** or wireless router.

Today, Wi-Fi is the most widely used wireless networking technology and is commonly found in homes, offices, schools, airports, hotels, cafés, and public places.

# 🌐 What is Wi-Fi?

**Wi-Fi** is a wireless communication technology based on the **IEEE 802.11** family of standards.

It enables wireless devices to communicate with one another and access network resources without requiring Ethernet cables.

Common Wi-Fi devices include:

- Laptops
- Smartphones
- Tablets
- Smart TVs
- Gaming consoles
- Printers
- IoT devices

---

# ⚙️ How Wi-Fi Works

A Wi-Fi network generally works as follows:

1. A Wireless Access Point (WAP) or wireless router broadcasts a wireless signal.
2. Wireless devices detect the available Wi-Fi network.
3. Users connect using the correct credentials.
4. The access point forwards data between the wireless devices and the wired network or the Internet.

Communication occurs using radio waves rather than physical cables.

# 🧩 Components of a Wi-Fi Network

A typical Wi-Fi network consists of:

### Wireless Router / Wireless Access Point

Provides wireless connectivity to nearby devices.

### Wireless Client

- Tablet

---

### Internet Connection

Provides access to external networks through the router.

# 📚 Wi-Fi Standards

Wi-Fi is based on the **IEEE 802.11** standard.

Some common versions include:

| Standard | Common Name |
|----------|-------------|
| IEEE 802.11a | Wi-Fi 1 |
| IEEE 802.11b | Wi-Fi 2 |
| IEEE 802.11g | Wi-Fi 3 |
| IEEE 802.11n | Wi-Fi 4 |
| IEEE 802.11ac | Wi-Fi 5 |
| IEEE 802.11ax | Wi-Fi 6 |

> The frequency bands used by Wi-Fi (2.4 GHz, 5 GHz, and 6 GHz) are covered in the **Wi-Fi Frequency Bands** section.

# ✅ Advantages

- No physical cables required.
- Supports user mobility.
- Easy installation.
- Multiple devices can connect simultaneously.
- Widely available.
- Supports Internet access and local communication.

---

# ❌ Limitations

- Limited coverage area.
- Signal interference may reduce performance.
- Speed decreases with distance.
- Physical obstacles can weaken the signal.
- Requires proper security configuration.
