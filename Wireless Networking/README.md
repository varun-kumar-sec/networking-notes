# Wireless Networking

> Learn the fundamentals of wireless networking, including wireless network types, wireless communication technologies, cellular networks, wireless devices, Wi-Fi frequency bands, and wireless security.

---

# 📖 Overview

Wireless networking enables devices to communicate and exchange data **without physical cables**. Instead of using wired media such as Ethernet cables, wireless networks use **radio waves** to transmit information between devices.

Wireless networking has become an essential part of modern computing and communication. It powers home Wi-Fi networks, corporate wireless infrastructures, public hotspots, Bluetooth devices, mobile communication, and Internet of Things (IoT) devices.

This module introduces the core concepts of wireless networking, explains different wireless network types, explores common wireless technologies, and covers the fundamentals of wireless security.
