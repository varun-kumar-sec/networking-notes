# What is an IP Address?
# 📖 Overview

An **IP Address (Internet Protocol Address)** is a unique logical address assigned to a device connected to a network. It identifies the device and enables it to communicate with other devices over a local network or the Internet.

Just as every house has a postal address for receiving mail, every device on a network requires an IP address so that data can be delivered to the correct destination.

Without IP addresses, devices would not know where to send or receive data.

# 🌐 What is an IP Address?

An **IP Address** is a numerical identifier assigned to a device connected to a network.

Examples of devices that use IP addresses include:

- Computers
- Smartphones
- Servers
- Routers
- Printers
- Smart TVs
- IoT Devices

Every device communicating over an IP network must have a unique IP address within that network.

---

# ❓ Why is an IP Address Needed?

An IP address is necessary because it:

- Identifies devices on a network.
- Enables communication between devices.
- Helps routers forward data to the correct destination.
- Allows devices to send and receive information.
- Makes Internet communication possible.

---

# 🎯 Purpose of an IP Address

An IP address serves two primary purposes:

## 1. Device Identification

Every device connected to a network is identified using an IP address.

Example:

```text
Laptop
IP Address:
192.168.1.10
```

---

## 2. Data Delivery

When data is transmitted, the destination IP address tells networking devices where the packet should be delivered.

Without an IP address, routers would not know the packet's destination.

---

# 🧩 Logical Addressing

An IP address is called a **logical address** because it is assigned by software or network administrators and can be changed if needed.

Unlike a **MAC Address**, which is permanently assigned to a network interface by the manufacturer, an IP address can be:

- Assigned manually
- Assigned automatically
- Changed when a device joins a different network

---

# 🌍 Real-World Example

Imagine sending a parcel.

The postal service needs:

- Sender's address
- Receiver's address

Similarly, in networking:

- Source IP Address → Identifies the sender.
- Destination IP Address → Identifies the receiver.

This allows data to travel across networks and reach the intended device.

# 📌 Key Takeaways

- An IP Address (Internet Protocol Address) uniquely identifies a device on a network.
- It enables devices to communicate over local networks and the Internet.
- IP addresses are logical addresses that can be assigned manually or automatically.
- Every device communicating over an IP network requires an IP address.
- Routers use IP addresses to forward data to the correct destination.
