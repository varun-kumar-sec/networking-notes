# 🌐 IP Addressing

IP Addressing is one of the fundamental concepts of computer networking. Every device connected to a network requires an **IP (Internet Protocol) address** so that it can be uniquely identified and communicate with other devices.

An IP address acts like a postal address for a device. Just as a postal address ensures that letters reach the correct destination, an IP address ensures that data packets are delivered to the correct device across local networks and the Internet.

This module introduces the fundamentals of IPv4 addressing, explains how IP addresses work, explores different types of IP addresses, and demonstrates how to configure and verify IP settings using common networking tools.
