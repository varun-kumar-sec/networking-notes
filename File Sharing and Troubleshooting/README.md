# File Sharing and Troubleshooting
# 📖 Overview

File sharing is one of the most common tasks performed in both home and business networks. It allows users to access, exchange, and collaborate on files and folders without relying on physical storage devices. Windows provides built-in tools for sharing folders, managing permissions, and controlling access to shared resources.

However, file sharing issues such as permission errors, network discovery problems, incorrect credentials, or disabled services can prevent users from accessing shared resources. Understanding how to troubleshoot these problems is an essential skill for IT support technicians and network administrators.

This module introduces the fundamentals of **file sharing**, explains different file sharing methods, demonstrates how to share folders in Windows, manage permissions and ownership, and troubleshoot common file sharing issues.

# 📌 Key Takeaways

- File sharing allows multiple users to access and collaborate on shared resources.
- Windows provides built-in features for sharing folders and controlling user access.
- Permissions and ownership play a critical role in protecting shared files.
- A systematic troubleshooting approach helps resolve file sharing problems efficiently.
- Modern Windows versions use **Function Discovery** and **SMB** for network discovery, while older systems may use the **Computer Browser** service.
