# Windows File Sharing
# 📖 Overview

Windows File Sharing is a built-in feature that allows users to share files and folders with other computers on a network. It enables multiple users to access the same resources without physically transferring files using USB drives or external storage devices.

Windows uses the **Server Message Block (SMB)** protocol for file and printer sharing. By configuring sharing settings and permissions, administrators can control who can view, modify, or manage shared resources.

This section explains the fundamental concepts of Windows file sharing and introduces the tasks involved in sharing, accessing, and securing folders.

# 🌐 How Windows File Sharing Works

Windows File Sharing follows a simple process:

1. A folder is selected for sharing.
2. Sharing is enabled.
3. Share permissions and NTFS permissions are configured.
4. Other users connect using the computer name or IP address.
5. Windows verifies the user's credentials and permissions before allowing access.

This process ensures that only authorized users can access shared files.

---

# 🔒 Security in Windows File Sharing

Windows provides several security features to protect shared resources:

- User authentication.
- Share permissions.
- NTFS permissions.
- File and folder ownership.
- Password-protected sharing.
- Windows Firewall integration.

Using these features together helps prevent unauthorized access while allowing legitimate users to collaborate.
